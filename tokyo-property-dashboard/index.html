日本购房政策详解（针对中国买家） 日本法务省，国税厅A 级

🏠 固定资产税
税率：评估价×1.7%/年。

都市计划税：评估价×0.3%/年（仅东京等都市圈）。

示例：¥6,000 万日元房产，年税额约¥102 万日元（人民币约¥4.9 万）。

注：评估价约为市场价的 60-70%
💰 资本利得税
税率：持有超 5 年：20.315%（长期）；持有 5 年内：39.63%（短期）

计算基础：卖出价 - 买入价 - 相关费用

亏损结转：可结转 3 年抵扣。
🏛️ 遗产税
外国人免税额：¥3,000 万日元 + ¥600 万×法定继承人数。

税率：10-55% 累进税率。

规划建议：通过日本法人持有可优化税务，但需注意公司税和年度申报。
🔓 购房限制
日本对海外买家购房无限制。

• 无需日本居住许可
• 可购买新房或二手房
• 可购买多套房产
• 无最低投资额要求

贷款限制：外国人通常需 30-40% 首付，利率略高，需提供收入证明。
🛂 签证/居留
购房与居留无直接关联。

• 购房不能直接获得签证
• 经营管理签证：投资¥500 万日元起
• 高度人才签证：积分制，70 分可申请永住

相关签证：工作签证、留学签证、配偶签证
