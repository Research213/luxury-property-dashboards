# 豪宅研究院 - 全球不动产战略监控看板

## 技能概述
面向高净值客户的国内一线城市不动产交易与配置业务的战略信息监控系统，实现政策、市场、竞争对手、技术等维度的自动化监控与警报。

## 核心监控维度

## 警报机制

### 警报级别
| 级别 | 触发条件 | 响应时间 | 推送方式 |
|------|---------|---------|---------|
| **P0 紧急** | 政策突变、市场拐点（房价单月>10%）、竞争对手重大并购 | 1 小时内 | 微信 + 短信 + 邮件 |
| **P1 重要** | 竞争对手大动作（佣金调整、核心团队流动）、市场异常（成交量>30% 波动） | 24 小时内 | 微信 + 邮件 |
| **P2 常规** | 月度数据更新、常规竞争对手动态 | 每周汇总 | 周报邮件 |

### 警报推送规则
- **政策突变**：限购/限贷/税费政策发布 → P0
- **市场拐点**：房价单月涨跌>10%、成交量连续 3 月>30% 波动 → P0
- **竞争对手大动作**：佣金费率调整>20%、核心团队整建制流动、重大融资/并购 → P1
- **土地市场异常**：土拍流拍率>50%、溢价率<5% 或>50% → P1
- **开发商风险**：头部房企债务违约、项目烂尾 → P0

## 使用说明

### 监控任务配置
1. **政策监控**：配置各城住建委、发改委、税务局官网 RSS 或爬虫
2. **市场数据**：订阅中指院、克而瑞、贝壳研究院月度报告
3. **竞争对手**：配置竞争对手官网、公众号、招聘网站监控
4. **舆情监控**：配置社交媒体关键词监控（城市 + 房产/中介/豪宅）

### 输出形式
- **实时警报**：微信/短信推送（P0/P1 级别）
- **日报**：政策 + 舆情摘要（邮件）
- **周报**：竞争对手动态 + 市场热点（邮件 + 文档）
- **月报**：完整市场数据 + 趋势分析（邮件 + 文档 + 会议）

### 更新维护
- 每月review 数据源有效性
- 每季度更新竞争对手清单
- 每半年优化警报阈值
