# 月度指数报告 Prompt 模板

## 🚀 快速启动

```
启动报告流程，我要撰写【2026 年 4 月】一线城市豪宅市场指数报告
```

---

## 📋 环节一：豪宅风向标

```
【豪宅风向标·[城市]】
项目名称：[楼盘名称]
网签数据：[套数/金额/环比同比]
产品特征：[面积段/容积率/产品线特点]
客群画像：[置换比例/年龄层/来源地]
调研反馈：[录音提炼/关键反馈]
```

**输出要求**：
- 新颖生活方式副标题（10-15 字）
- 产品线稀缺物理属性
- 客观陈述地段、配套、圈层与性价比（300-350 字）

---

## 📊 环节二：16 段微观分析

### 模板 A：新房价格分析
```
【新房价格·[城市]】
均价：[X 元/㎡]，环比 [X%]，同比 [X%]
结构变化：[面积段/产品系占比变化]
价格异动项目：[项目名称 + 涨跌幅]
调研反馈：[折扣率/以价换量情况]
```

### 模板 B：二手房成交量分析
```
【二手成交量·[城市]】
网签量：[X 套]，环比 [X%]，同比 [X%]
活跃度分级：[核心区/郊区对比]
置换链条：[卖一买一比例/周期]
调研反馈：[带看量/议价空间]
```

**输出要求**：每段 200-300 字，严格量价拆分

---

## 📈 环节三：总体数据分析

```
进入宏观分析节点
```

**输出模块**：
1. 二手价格共性特征与分化（200-300 字）
2. 二手活跃度共性特征与分化（200-300 字）
3. 新房价格共性特征与分化（200-300 字）
4. 新房活跃度共性特征与分化（200-300 字）

---

## 🔮 环节四：中短期研判

```
【中短期研判】
基于上述分析，预判未来 3-6 个月：
- 新房市场：[去化/价格走势]
- 二手市场：[去化/价格走势]
```

**要求**：严格控制在 150 字以内

---

## 🌟 环节五：月度亮点

```
本月补充外部热点：
1. [土拍/政策/规划事件 1]
2. [土拍/政策/规划事件 2]

生成月度亮点
```

**输出要求**：
- 15 字以内客观小标题
- 单条 100-250 字
- 只摆事实，不做推导

---

## 💡 环节六：核心洞察

```
生成核心洞察
```

**三段论逻辑**：
1. 现象观察（数据/行为表象）
2. 深度归因（精确到产品/客户属性）
3. 结构性结论（中短期预判）

---

## ✅ 环节七：检查清单

```
触发检查清单
```

**检查项**：
- [ ] 指数绝对值准确性
- [ ] 时钟图完整性
- [ ] 新房百盘榜单插入
- [ ] 二手百盘榜单插入
- [ ] 数据来源标注完整
- [ ] 禁用词汇检查

---

## 🎨 排版规范

### 标题层级
```markdown
# 一级标题（报告名称）
## 二级标题（章节）
### 三级标题（小节）
```

### 数据呈现
```markdown
| 城市 | 新房均价 | 环比 | 同比 |
|------|----------|------|------|
| 北京 | 85,000   | -2%  | -8%  |
| 上海 | 92,000   | +1%  | -5%  |
```

### 关键结论
```markdown
**核心结论**：[加粗标注]
```

## ⚠️ 行文红线

### 禁用词汇
❌ 暴涨、腰斩、恐慌性抛售、火爆、绝版、秒杀

### 推荐词汇
✅ 价格回调、以价换量、去化周期拉长、结构性异动、观望情绪浓厚
