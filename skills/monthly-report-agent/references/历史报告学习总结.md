## 🎯 用词风格总结

### 市场定位表述

| 市场状态 | 推荐表述 |
|---------|---------|
| 买方市场 | 强买方市场、买方主导、供给量大于需求量 |
| 价格趋势 | 价格持续探底、价格持续调整、价格回调 |
| 成交策略 | 以价换量、比价竞低、价格成为关键成交因素 |
| 预期状态 | 买卖预期深度博弈、预期分歧加剧、探底心态 |
| 市场分化 | 结构性分化、成交分化、核心资产走强 |

### 城市分析标题模板

**价格指数**：
- 北京：[市场状态]，[成交特征]
- 上海：[预期状态]，[价格趋势]
- 深圳：市场稳健调整，"高品质 + 有效让价"形成市场路径
- 广州：成交量较低，价格相对稳定

**活跃度指数**：
- 🔹北京：[带看/成交特征]，[关键因素]
- 🔹上海：[季节性/板块特征]，[热度状态]
- 🔹深圳：[支撑因素] 推动活跃度
- 🔹广州：活跃度 [季节性/市场性] 回落

### 示例（2026 年 3 月）

```markdown
1. **北京新房豪宅优质盘价格松动对二手带来冲击**

3 月"小阳春"北京全市二手住宅成交量接近 2 万套处于较高水平，但二手豪宅市场成交量依然维持稳定，其中核心影响因素之一在于新房豪宅冲击，3 月份北京润园二期入市，产品力强且稀缺，同时价格优势明显，以及其他热销新房纷纷调整价格，抓住"小阳春"窗口期，需求流向新房。

1. **上海"沪七条"效应叠加"小阳春"季节性因素成交量增长明显**

3 月份上海无论全市二手住宅还是豪宅市场成交量环比增长明显，全市二手住宅成交量超过 2.7 万套，二手豪宅成交量同比基本持平。同时个别产品力好且价格优势强的盘成交量较高，例如翠湖天地单盘成交量达到 9 套，仁恒河滨城成交 7 套。
```

## 💡 核心洞察三段论

### 结构
```markdown
1. **[核心观点标题]**

（1）[现象/趋势描述]

主要原因有：
① [原因 1]
② [原因 2]
③ [原因 3]

（2）[分化/对比分析]

**（1）新房端**：[新房特征]

**（2）二手端**：[二手特征]

1. **[未来预判]**

预计 [时间范围]，[趋势预判]。[支撑逻辑]。
```

### 示例（2026 年 3 月）

```markdown
1. **3 月一线城市全市二手市场"小阳春"成交量热度较高，但价格持续调整**

（1）成交量回升的主要原因有：

①因春节月被动积压的真实需求集中入市；
②新房端优质供应的放量激活需求入市
③叠加近期部分城市（如上海）限购及信贷优化政策的实质性刺激。

（2）价格持续调整的原因有：

①二手市场挂牌成交比维持高位，例如北京豪宅市场挂牌成交比在 30:1 以上。这意味着供给端的"比价竞低"策略仍将维系，**成交量不会支撑价格，反而会推动价格调整**。
②新房市场，开发商主动让利。

1. **豪宅市场成交分化**

**（1）新房端**：开发商普遍在 3 月份"小阳春"市场节点入市或调整价格抢占时机，市场上的优质项目，具备地段与产品优势（如北京润园、上海高福云境与绿城潮鸣外滩、广州保利玥玺湾等）实现了集中去化，加剧了新房之间的竞争及对二手市场的虹吸。

**（2）二手端**：高库存下供给端"比价竞低"仍是成交核心，3 月份成交数据来看热销盘/房价格具有明显优势，产品好且价低，性价比优势明显。

1. **预计"小阳春"过后，市场成交量将回归稳定**

预计整体市场成交量将维持稳定，市场成交将会持续分化，优质稀缺产品且具有价格优势产品将会成为市场成交主力，价格高于市场或产品力弱的盘/房成交活跃度减弱，价格下调空间大，特别是新房冲击大的二手盘将会面临较大冲击。
```
