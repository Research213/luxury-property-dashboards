## 💡 使用方式

### 方式 1：直接对话（推荐）

直接发送以下指令开始：

```
启动报告流程，我要撰写【2026 年 4 月】一线城市豪宅市场指数报告
```

### 方式 2：分步执行

```
【北京·新房市场】
网签数据：本月网签 1,200 套，环比 +15%，同比 -8%
均价：85,000 元/㎡，环比 -2%
调研反馈：改善型客户占比提升至 65%
典型项目：中建壹品·京玥
```

### 方式 3：推进流程

```
16 段分析已确认，进入宏观分析节点
```

```
本月补充外部热点：

生成洞察
```

## 📋 标准工作流（7 环节）

### 环节 1️⃣：豪宅风向标
- 提炼典型楼盘
- 输出 300-350 字客观分析

### 环节 2️⃣：16 段微观分析
- 北上广深 × 新房/二手 × 价格/成交量
- 每段 200-300 字

### 环节 3️⃣：总体数据分析
- 四大模块提炼
- 共性特征与分化

### 环节 4️⃣：中短期研判
- 未来 3-6 个月预判
- 严格 150 字以内

### 环节 5️⃣：月度亮点
- 新闻快讯体
- 100-250 字/条

### 环节 6️⃣：核心洞察
- 三段论逻辑
- 现象→归因→结论

### 环节 7️⃣：回顾检查
- 清单核对
- 数据准确性确认

## ⚠️ 行文红线

### 禁用词汇
❌ 暴涨、腰斩、恐慌性抛售、火爆、绝版、秒杀

### 推荐词汇
✅ 价格回调、以价换量、去化周期拉长、结构性异动、观望情绪浓厚
